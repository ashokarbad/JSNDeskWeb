Workspace 5 screens

              

                
Formatter

                

                  
Pretty-print, minify or escape JSON, with indent, sort-keys and Unicode-escape options.

                  
A language menu on the input also formats XML, YAML, CSV, Plist, TOML, Properties and .env files, and encodes or decodes Base64, URL and Unicode text.

                

              

              

                
Validator

                
Checks your JSON and points to the exact line and column of each error.

              

              

                
Explorer

                
Browse a document as a collapsible tree, a table, or raw text.

              

              

                
Compare

                
Diff two documents and jump from one change to the next.

              

              

                
JSONPath

                
Query a document with JSONPath expressions, with autocomplete and a cheat sheet next to the editor.

              

            


            

              
Library 4 screens

              

                
JSON Store

                
Keep documents organized as project, folder and document, with tags, favorites, locking, search, and drag and drop.

              

              

                
Schema

                
Generate a JSON Schema from sample JSON, or validate a document against one. Generation options sit in the right-hand panel.

              

              

                
Projects

                
One dashboard per project for its documents, requests, schemas and queries. Pin the projects you open most.

              

              

                
Recently Deleted

                
Deleted documents, projects with their saved items, requests, schemas, queries and saved APIs are kept for the period you choose. Restore them, or remove them for good.

              

            


            

              
Tools 5 screens

              

                
Generator

                
Create sample JSON from an example document or from a JSON Schema.

              

              

                
Converter

                

                  
Convert between JSON and YAML, CSV, TSV, XML, TOML, Properties, plist and query strings. Choose input and output formats separately, and swap them with one click.

                  
Generate model code in Swift, Kotlin, TypeScript, Java, Dart, Go, C# and Python.

                

              

              

                
API Client

                
Send HTTP requests with custom headers and a body, and read the response. Saved APIs, environments with {{variables}}, cURL, Postman and OpenAPI support. See the API Client

              

              

                
Mock Generator

                
Build fake records such as names, emails and dates from a list of fields, as one object or a list. Object and List fields can hold nested fields.

              

              

                
JWT

                
Decode tokens, verify HS256, HS384 and HS512 signatures, and create signed tokens. The secret is never saved to disk.

              

            


            

              
Settings

              

                
Make it yours

                

                  
Theme, accent color, code font size and line wrapping. Default formatter options, request timeout, the screen to open on launch, and the splash screen.

                  
Choose which item types show on the Projects screen and whether the API Client shows its cURL menu. Set how long deleted items are kept, export or import a backup, or clear all data.

Your JSON stays on your Mac

            
JSON often holds customer records, API keys and tokens. JSON Desk is built so none of it goes anywhere you didn't send it.

            Read the privacy policy
          

          
    
            
  • No account, no analyticsThere's nothing to sign up for, and no tracking or third-party code in the app.
    • 
            
  • Stored on your MacYour library lives in one file inside the app's sandbox, and you can export a backup at any time.
    • 
            
  • Network only when you sendThe app connects to the internet only for API Client requests, to the URLs you enter.
    • 
            
  • JWT secrets aren't savedThe secret you use to verify or sign a token is never written to disk.
