Format, validate and explore JSON on your Mac.

JSON Desk is a native macOS app for everyday JSON work. It keeps your documents organized in projects, and nothing leaves your Mac unless you send a request yourself.

What's in the sidebar

        
Fourteen screens grouped the way you work: edit in the Workspace, keep things in the Library, reach for Tools when you need them.


        

          
Workspace

          

            
Formatter
Pretty-print, minify or escape JSON, with indent, sort-keys and Unicode-escape options.

            
Validator
Shows the exact line and column of every error.

            
Explorer
Browse a document as a collapsible tree, a table, or raw text.

            
Compare
Diff two documents and jump from one change to the next.

            
JSONPath
Run JSONPath queries with autocomplete and a built-in cheat sheet.

          

        


        

          
Library

          

            
JSON Store
Projects, folders and documents, with tags, favorites, locking, search and drag and drop.

            
Schema
Generate a JSON Schema from sample data, or validate a document against one.

            
Projects
One dashboard per project for its documents, requests, schemas and queries. Pin the ones you use most.

            
Recently Deleted
Deleted items wait here for a period you choose, so you can restore them.

          

        


        

          
Tools

          

            
Generator
Create sample JSON from an example document or a JSON Schema.

            
Converter
Turn JSON into YAML, CSV, XML, or Swift and Kotlin model code.

            
API Client
Send HTTP requests with custom headers and a body, then inspect the response.

            
Mock Generator
Build fake records with names, emails, dates and more from a list of fields.

            
JWT
Decode tokens, verify HS256, HS384 and HS512 signatures, and create signed tokens.

          

        


        

          
Settings

          

            
Look and feel
Theme, accent color, code font size and line wrapping.

            
Your defaults
Formatter options, request timeout, the screen to open on launch, and how long deleted items are kept.

            
Backups
Export the whole library to a single JSON file, and import it on any Mac.

Your JSON stays on your Mac

            
JSON often holds customer records, API keys and tokens. JSON Desk is built so that none of it goes anywhere you didn't send it.

            Read the privacy policy
          

          
    
            
  • No account, no analyticsThere's nothing to sign up for, and the app has no tracking or third-party code.
    • 
            
  • One local library fileProjects and documents live in a single file inside the app's sandbox. Export a backup whenever you like.
    • 
            
  • Network only when you askThe only outgoing connections are the requests you send from the API Client, to the URLs you enter.
    • 
            
  • Secrets aren't savedJWT signing secrets are kept in memory only and never written to disk.
