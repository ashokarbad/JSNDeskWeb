Environments and variables
Keep values like {{baseUrl}} per environment. A path such as /posts picks up the active base URL.

          
Auth in one tab
Add Bearer, Basic or API-key headers from the Auth tab, using variables for the secrets.

          
Capture values
Save a value from the response body with a JSONPath, or from a response header, into the active environment. Insert a saved value into a header with Add Header › From Variable.

          
Login token, handled
When a response contains a login token, a bar offers to use it. Pick the field, such as accessToken or refreshToken, and later requests are sent with it automatically. It is kept in memory only, and "Not for this API" turns it off for one API.

          
Saved APIs
Organize requests as project, folder and API. Save suggests a name such as “GET products” that you can edit. Duplicate one, move a whole project with Move All to Project, or lock one so it can still be sent but not edited, renamed, moved or deleted.

          
Request history
The clock button lists your last 50 requests with their responses. Load one, or save it to Saved APIs. Secrets in headers and the Auth tab are not kept.

          
Read the response
See headers, time and size. Search the body, and click a line to copy its value. Large responses show in full.

          
Save what you find
Send a JSON response to the JSON Store, or right-click a saved API and choose Save as Note to keep the request and response together.

          
Bring your collections
Import cURL, Postman, and OpenAPI or Swagger in JSON or YAML. Re-importing adds only what's new. Export a project as a Postman collection.

        

        
Cookies are kept between requests unless you turn that off in Settings. The API Client is the only part of JSON Desk that uses the network, and it only contacts the addresses you enter.

Workspace 5 screens

              

                
Formatter

                

                  
Pretty-print, minify or escape JSON, with indent, sort-keys and Unicode-escape options.

                  
A language menu on the input also formats XML, YAML, CSV, Plist, TOML, Properties and .env files, and encodes or decodes Base64, URL and Unicode text.

                

              

              

                
Validator

                
Checks your JSON and points to the exact line and column of each error.

              

              

                
Explorer

                
Browse a document as a collapsible tree, a table, or raw text, and search keys and values. The tree and table are read-only, but you can select and copy text, and right-click a tree row to copy its value, key or path.

              

              

                
Compare

                
Diff two documents and jump from one change to the next. Ignore key order when it doesn't matter, and save the differences as a text file.

              

              

                
JSONPath

                
Query a document with JSONPath expressions, with autocomplete and a cheat sheet next to the editor.

              

            


            

              
Library 5 screens

              

                
JSON Store

                
Keep documents organized as project, folder and document, with tags, favorites, locking, search, and drag and drop. Create, rename and delete folders, even empty ones. Name the Unassigned group to turn it into a project, or delete it. A document you move leaves its old folder behind.

              

              

                
Schema

                
Generate a JSON Schema from sample JSON, or validate a document against one. Generation options sit in the right-hand panel.

              

              

                
Projects

                
One dashboard per project with cards for its documents, saved APIs, notes, schemas and queries. Click a saved API for a popup with all its details, and open it in the API Client from there. Choose which cards appear in Settings, and pin the projects you open most.

                
When notes are grouped by project, the dashboard shows its three newest notes, and Show all opens them in Notes.

              

              

                
Notes

                

                  
Write general notes in free text, or API notes that record a URL, request, optional headers and the response you got back.

                  
Show notes as one list, or group them by project and folder like the JSON Store (in Settings, off by default). Sort by name, date created or date modified, add favourites and tags, and lock a note so it can be read and copied but not changed. Deleting a note asks first.

                  
In an API note, a request or response that is valid JSON gets the Formatter's syntax colors, and the URL and request have Copy buttons. The response box grows with the response. Press ⌘F or the magnifier to find text inside the note, with matching lines highlighted.

                  
Export one note, several, or a whole project's notes as Markdown or text, or as a PDF laid out as clean white pages with each note on a new page. An API note can be reopened in the API Client, and its response can be copied, exported or saved to the JSON Store.

                

              

              

                
Recently Deleted

                
Deleted documents, projects with their saved items, notes, requests, schemas, queries and saved APIs are kept for the period you choose. Restore them, or remove them for good.

              

            


            

              
Tools 5 screens

              

                
Generator

                
Create sample JSON from an example document or from a JSON Schema.

              

              

                
Converter

                

                  
Convert between JSON and YAML, CSV, TSV, XML, TOML, Properties, plist and query strings. Choose input and output formats separately, and swap them with one click.

                  
Generate model code in Swift, Kotlin, TypeScript, Java, Dart, Go, C# and Python.

                

              

              

                
API Client

                
Send HTTP requests with headers, a body and Bearer, Basic or API-key auth, and read the response with its headers, time and size. Capture values into environments, use a login token automatically, look back through your last 50 requests, keep saved APIs, and import cURL, Postman and OpenAPI. See the API Client

              

              

                
Mock Generator

                
Build fake records such as names, emails and dates from a list of fields, as one object or a list. Object and List fields can hold nested fields, and ⌘Z undoes adding or removing one.

              

              

                
JWT

                
Decode tokens, verify HS256, HS384 and HS512 signatures, and create signed tokens. The secret is never saved to disk.

Theme, accent color, code font size and line wrapping. Default formatter options, request timeout, whether cookies are kept between requests, the screen to open on launch, the splash screen, and the app walkthrough.

Turn request history and input history on or off, and clear them. On every screen

        

        

          
Save to a project
Save results from most screens straight into a project.

          
Drag files in
Drop a text or JSON file onto any input editor to load it.

          
Export and share
Save any output as a file, PDF or image, or share it with AirDrop. Each export asks which folder to save in, then shows the full path with a Show in Finder button. Notes and JSON Store documents can be saved as PDF too. Sort documents and notes by name or date, and duplicate them from their lists.

          
Keyboard first
⌘1–⌘9 and ⌥⌘1–⌥⌘5 jump to screens, ⌘K opens the command palette, ⌘F searches the current editor or the open note, and ⌘/ lists every shortcut. Change any of them in Settings.

          
Search everything
⌘K also searches your documents, notes, saved requests and API Client requests. Turn on Spotlight in Settings to find documents and notes from outside the app. Locked items are never included. Every search box has a small cross to clear it.

          
Select several
⌘-click or ⇧-click to pick several items, then right-click to lock, move, favourite, export or delete them.

          
Windows and tabs
Open several windows or tabs with File › New Window or New Tab. They share your library, and the app remembers window position and pane sizes. Toolbars adapt to a narrow window.

          
Undo a delete
Deleting a document, note or project shows an Undo. Everything also waits in Recently Deleted.

          
Drag files out
Drag a document from the JSON Store to Finder for a .json file. A note becomes a text file, or a Postman collection for API notes.

          
History on every tool
The Formatter, Validator, Explorer, Compare, JSONPath, Converter and Generator each have a History button with that screen's last 50 inputs. Click one to bring it back. Turn it off or clear it in Settings.

          
Keeps your place
Switching screens keeps your work, and the Tools screens remember what you last entered.

          
Hide the sidebar
Use the button at the top left of the window, View › Hide Sidebar, or ⌃⌘S when you want the whole window for the editor.

          
Native menus
File opens, imports and exports. Edit has Find in Editor. View sets the sidebar, inspector, code text size, line wrapping and theme. Go lists every screen, and Help has the walkthrough, in-app help and shortcuts.

          
Built for big files
Editors and read-only panes are native text views with line numbers, so long files scroll smoothly. Long outputs have a scroll-to-top button.

          
A walkthrough to start
A nine-slide walkthrough appears the first time you open the app. Open it again from Help › App Walkthrough.
