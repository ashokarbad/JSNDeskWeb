Getting started

What do I need to run JSON Desk?

A Mac running macOS 14 Sonoma or later. JSON Desk is free on the Mac App Store.

Which formats does it work with besides JSON?

Formatter: pick a language on the input to format XML, YAML, CSV, Plist, TOML, Properties and .env files, or to encode and decode Base64, URL and Unicode text.

Converter: convert between JSON and YAML, CSV, TSV, XML, TOML, Properties, plist and query strings, and generate model code in Swift, Kotlin, TypeScript, Java, Dart, Go, C# and Python.

How do I open a file?

Drag a text or JSON file onto any input editor. The editor shows a hint while you drag, and loads the file when you drop it. You can also paste straight into any editor.

How do I export or share a result?

Use the Export menu on any output to save it as a file, PDF or image, or to share it through the macOS share menu, including AirDrop. Most screens can also save their result straight into a project.

Are there keyboard shortcuts?

⌘K opens the command palette, where you can jump to any screen or action. ⌘F searches the current editor or output.

Will formatting change my keys or numbers?

No. JSON Desk keeps keys in their original order and leaves numbers exactly as written, so 1.50 stays 1.50. Keys are only reordered if you turn on the sort-keys option.

Your data

Where is my data stored?

Your library (documents, projects, requests, schemas, queries and Recently Deleted) is a single file called store.json inside the app's sandbox. To find it, choose Go › Go to Folder in Finder, enter ~/Library/Containers, open the JSON Desk folder, then go to Data/Library/Application Support/JsonStudio. The folder keeps its old name so libraries from earlier versions still load.

Settings, recent tool inputs, and the API Client's saved APIs and environments are kept in the app's preferences in the same container.

How do I back up my library or move it to another Mac?

Open Settings and choose Export to write your whole library to one JSON file. On the other Mac, open Settings, choose Import and pick that file.

Import replaces the library on that Mac rather than merging with it, so export a backup there first if it has anything you want to keep.

The API Client keeps its saved APIs and environments separately from the library. To move them too, export each API Client project as a Postman collection and import it on the other Mac.

I deleted something by mistake. Can I get it back?

Open Recently Deleted in the Library section of the sidebar and restore it. Documents, projects with their saved items, requests, schemas, queries and saved APIs are kept there for the period set in Settings. Once an item is removed from Recently Deleted, it can only come back from a backup.

The app opened with an empty library. Is my data gone?

Probably not. If JSON Desk can't read the library file, it first saves a copy named store.unreadable-<timestamp>.json in the same folder, then starts a fresh library. Nothing is overwritten.

Email us with that file, or a description of what it holds, and we'll help you recover it. If you have a backup, you can import it from Settings.

Does locking a document encrypt it?

No. Locking makes a document read-only so it can't be changed by accident. Your data is stored as plain text, protected by your Mac user account and FileVault.

How do I erase everything?

Open Settings and choose Clear all data. This removes everything the app has saved and can't be undone, so export a backup first if you might need anything later.

How do I remove JSON Desk completely?

Export a backup first if you want to keep anything. Then drag JSON Desk from Applications to the Trash, and delete its folder in ~/Library/Containers to remove its library and settings.

API Client

How do environments and variables work?

An environment holds values such as {{baseUrl}} and {{token}}. Use them in the address, headers or body, and JSON Desk fills them in from the active environment when you send.

If you enter just a path, such as /posts, the active environment's base URL is added in front of it.

Can I bring in requests from cURL, Postman or Swagger?

Yes. Import a cURL command, a Postman collection, or an OpenAPI or Swagger file, and copy any request as cURL. You can also export a project as a Postman collection.

If you don't use cURL, you can hide the cURL menu in Settings.

Are my tokens and API keys stored?

Header values and environment variables you save are stored in the app's preferences as plain text, and are included in Postman collections you export. They never leave your Mac unless you send a request or share an export. Avoid saving live production secrets. The JWT screen's secret is the exception: it is never saved.

A request fails or times out. What should I check?
  • Make sure the right environment is active, so variables like {{baseUrl}} resolve to the server you expect.
  • Try the same address in a browser or with cURL to rule out the server or your network.
  • Raise the request timeout in Settings if the server is slow to respond.
Why does JSON Desk need network access?

Only for the API Client. Requests go straight from your Mac to the address you enter. The app doesn't contact any other server, and has no analytics of its own.

Menu bar and Shortcuts

How do I use the menu bar icon?

Copy some JSON, click the JSON Desk icon in the menu bar, and choose Format, Minify or Validate. The icon briefly shows a check when it worked, or a warning if the clipboard doesn't hold valid JSON. Format and Minify put the result back on your clipboard.

I can't see the menu bar icon.

When the menu bar is full, macOS hides icons that don't fit, especially on Macs with a notch. Quit a few menu bar apps or shorten the clock, and check the menu bar settings in System Settings to make sure JSON Desk is allowed to show its icon.

How do I use JSON Desk in Shortcuts or Spotlight?

Open the Shortcuts app, create a shortcut, and search for JSON Desk to add its actions to format, validate or convert JSON. Combine them with actions like Get Clipboard and Copy to Clipboard. The same actions are available from Spotlight.

Reporting a bug

Including these details helps us fix things quickly:

  • Your JSON Desk version (JSON Desk › About JSON Desk) and macOS version.
  • The screen you were on and the steps that lead to the problem.
  • What you expected to happen, and what happened instead.
  • A small sample of JSON that shows the problem. Remove passwords, tokens and personal data first.
  • A screenshot or screen recording, if it helps.
