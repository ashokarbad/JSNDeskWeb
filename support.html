Getting started

What do I need to run JSON Desk?

A Mac running macOS 14 Sonoma or later. JSON Desk is free on the Mac App Store.

Which formats does it work with besides JSON?

Formatter: pick a language on the input to format XML, YAML, CSV, Plist, TOML, Properties and .env files, or to encode and decode Base64, URL and Unicode text.

Converter: convert between JSON and YAML, CSV, TSV, XML, TOML, Properties, plist and query strings, and generate model code in Swift, Kotlin, TypeScript, Java, Dart, Go, C# and Python.

How do I open a file?

In Finder, Control-click a file and choose Open With › JSON Desk. It opens in the Formatter, or in the Converter for TSV files. JSON Desk opens .json, .jsonc, .geojson, .xml, .yaml, .yml, .csv, .tsv, .toml, .properties, .env, .plist and .txt files.

You can also drag a file onto any input editor, which shows a hint while you drag, or paste straight into any editor.

To open a file type with JSON Desk every time, select the file in Finder, choose File › Get Info, pick JSON Desk under Open with, and click Change All.

How do I export or share a result?

Use the Export menu on any output to save it as a file, PDF or image, or to share it through the macOS share menu, including AirDrop. Most screens can also save their result straight into a project.

Every export asks which folder to save in, starting in the last one you used. Afterwards, the message shows the full path with a Show in Finder button.

Notes and JSON Store documents can be saved as PDF too: right-click and choose Export. Each note starts on a new page, with its title, method and URL, then the request, headers and response in colored, indented blocks on a clean white page. If you export several notes, JSON Desk asks whether to save one file or one file per note.

Can I bring back something I entered earlier?

Yes. The Formatter, Validator, Explorer, Compare, JSONPath, Converter and Generator each have a History button. It lists the last 50 inputs of that screen. Click one to bring it back.

History is saved a moment after you stop typing, in a file on your Mac. Text that isn't JSON, such as a copied note, is not recorded on the JSON screens. Turn history off, or clear it, in Settings › Data.

Where is the welcome walkthrough?

A nine-slide walkthrough appears the first time you open the app, with Back, Next and Skip. To see it again, choose Help › App Walkthrough… or open it from Settings › General.

Can I open more than one window?

Yes. Choose File › New Window or New Tab. All windows share your library, so a change in one shows in the others. JSON Desk remembers window position and pane sizes.

How do I act on several items at once?

In the JSON Store, Notes and the API Client's saved list, ⌘-click or ⇧-click to select several items, then right-click. Depending on the list, you can lock, move, favourite, export, delete or save them as notes.

How do I find something quickly?

Press ⌘K. Besides screens and actions, it searches your documents, notes, saved requests and API Client requests. ⌘F searches the current editor or output, and Explorer can search keys and values.

Every search box has a small cross that clears it. To find documents and notes from Spotlight, turn that on in Settings. Locked documents and notes are never included.

How do I hide the sidebar?

Click the sidebar button at the top left of the window, choose View › Hide Sidebar, or press ⌃⌘S. Do the same to show it again.

What is in the app's menus?
  • File: New Window, New Tab, Open, Import backup, Postman, OpenAPI or cURL import, and Export Backup.
  • Edit: Find in Editor.
  • View: sidebar, inspector, code text size, wrap lines and theme.
  • Go: every screen.
  • Help: the app walkthrough, in-app help and keyboard shortcuts.

JSON Desk › About JSON Desk shows the version.

Can it open large files?

Yes. Editors and read-only panes use native text views with a line-number index that is built as you scroll, so long files stay smooth. Long outputs have a scroll-to-top button.

Will formatting change my keys or numbers?

No. JSON Desk keeps keys in their original order and leaves numbers exactly as written, so 1.50 stays 1.50. Keys are only reordered if you turn on the sort-keys option.

Your library

What is on a project's dashboard?

Each project has cards for its documents, saved APIs, notes, schemas and queries. Click a saved API to open a popup with all its details, and open it in the API Client from there. Choose which cards to show in Settings.

The notes card shows the project's three newest notes, and only when Settings › Notes groups notes by project. Show all opens them in Notes.

I moved a document. Why is its old folder still there?

Moving a document leaves its old folder in place, even when the folder is now empty, so your structure doesn't change unexpectedly. Rename or delete folders yourself from the JSON Store. You can also create empty folders ahead of time.

What is the Unassigned group?

It holds documents that don't belong to a project yet. Give it a name to turn it into a project, or delete it.

What's the difference between a general note and an API note?

A general note is free text. An API note records a URL, the request, optional headers and the response, which is handy for keeping examples of how an API behaves.

Notes are shown as one list, which you can sort by name, date created or date modified, ascending or descending. To group them by project and folder like the JSON Store, turn that on in Settings › Notes. Deleting a note asks first.

In an API note, a request or response that is valid JSON appears with syntax colors. Choose Edit for the plain editor and Done to go back. Headers are hidden, and the request can be shown or hidden. An empty request is hidden, and Add Request brings it back. The URL and request have Copy buttons, and the response box grows with the response and has Copy, Export and Save to JSON Store buttons. Press ⌘F or click the magnifier to find text inside the note.

How do I export or share a note?

Right-click a note and choose Export to save it as Markdown, text or PDF. Select several notes, or use a project's menu, to export many as Markdown.

You can also drag a note to Finder. A general note becomes a .txt file, and an API note becomes a Postman collection that the API Client can import. Drag a document out of the JSON Store to get a .json file.

What does locking a note or document do?

A locked note can be read and copied but not edited, moved or deleted. Lock it from the lock icon in the list, or by right-clicking. Locked documents and notes are also left out of Spotlight. Locking is not encryption.

I deleted a document, note or project. Can I undo it?

Click Undo in the message that appears right after you delete. If you miss it, the item still waits in Recently Deleted.

Where is my data stored?

Your library (documents, projects, folders, notes, requests, schemas, queries and Recently Deleted) is a single file called store.json inside the app's sandbox. To find it, choose Go › Go to Folder in Finder, enter ~/Library/Containers, open the JSON Desk folder, then go to Data/Library/Application Support/JsonStudio. The folder keeps its old name so libraries from earlier versions still load.

Settings, recent tool inputs, and the API Client's saved APIs and environments are kept in the app's preferences in the same container.

How do I back up my library or move it to another Mac?

Open Settings and choose Export to write your whole library to one JSON file. It includes your saved APIs with their folders and environments. On the other Mac, open Settings, choose Import and pick that file.

Import replaces the library on that Mac rather than merging with it, so export a backup there first if it has anything you want to keep.

To move just one project's saved APIs, you can also export it as a Postman collection and import it on the other Mac.

I deleted something by mistake. Can I get it back?

Open Recently Deleted in the Library section of the sidebar and restore it. Documents, projects with their saved items, notes, requests, schemas, queries and saved APIs are kept there for the period set in Settings. Once an item is removed from Recently Deleted, it can only come back from a backup.

The app opened with an empty library. Is my data gone?

Probably not. If JSON Desk can't read the library file, it first saves a copy named store.unreadable-<timestamp>.json in the same folder, then starts a fresh library. Nothing is overwritten.

Email us with that file, or a description of what it holds, and we'll help you recover it. If you have a backup, you can import it from Settings.

Does locking a document encrypt it?

No. Locking makes a document read-only so it can't be changed by accident. Your data is stored as plain text, protected by your Mac user account and FileVault.

How do I erase everything?

Open Settings and choose Clear all data. This removes everything the app has saved and can't be undone, so export a backup first if you might need anything later. The separate Clear button only resets the Tools screens' saved inputs.

How do I remove JSON Desk completely?

Export a backup first if you want to keep anything. Then drag JSON Desk from Applications to the Trash, and delete its folder in ~/Library/Containers to remove its library and settings.

API Client

How do environments and variables work?

An environment holds values such as {{baseUrl}} and {{token}}. Use them in the address, headers or body, and JSON Desk fills them in from the active environment when you send.

If you enter just a path, such as /posts, the active environment's base URL is added in front of it.

How do I add authentication to a request?

Open the Auth tab and choose Bearer, Basic or API key. JSON Desk adds the matching header for you. You can put a variable such as {{token}} in the value, so each environment can use its own.

How do I reuse a login token or a value from a response?

The easiest way is the login-token bar. When a response contains a login token, a bar offers to use it. Choose the field from the dropdown, such as accessToken or refreshToken, and every later request is sent with Authorization: Bearer <token> automatically. The header shows as a row in the Headers tab. Click the ? button for the steps.

The token is kept in memory only and is forgotten when you quit the app.

JSON Desk skips requests that have their own Authorization header, and login-style URLs. To turn the token off for one API, choose Not for this API. That API is then also sent without stored cookies.

To store other values from a response, use the Capture tab. It saves a value from the response body, using a JSONPath, or from a response header into the active environment. The response's Headers tab also has a Capture button on each header.

To use a saved value in a header, choose Add Header › From Variable. It inserts the value as {{name}}.

What can I do with a response?

You see the response, its headers, the time and the size. Search it, and click a line to copy its value. Use Copy and Export, or the tray button to save a JSON response to the JSON Store. You choose the project and folder, and can type a new folder.

Responses up to about a million characters are shown in full.

How do I keep a request and its response together?

Right-click a saved API and choose Save as Note. The note holds the full URL, the headers and the response. If the request is already saved as a note, JSON Desk tells you. You can open an API note back in the API Client.

Why did a saved request lose its last response after I restarted?

A saved API's last response is kept until you quit the app, so switching between APIs doesn't clear it. To get an earlier response back after a restart, open the request History, which keeps responses across restarts. To keep one for good, save it to the JSON Store or as a note.

What is the request history?

The clock button in the API Client lists the last 50 requests you sent, with their responses. Click one to load it, or save it to Saved APIs. Request history keeps responses across restarts.

Secrets in headers and in the Auth tab are not kept in history. You can turn history off, or clear it, in Settings › Network.

How do I save a request?

Press Save. JSON Desk suggests a name, such as “GET products”, that you can edit. If the request is already saved, it tells you.

Why does a GET request have no Body tab?

A GET request doesn't carry a body, so the tab is hidden. Switch the method, for example to POST, and the Body tab appears.

How do I move many saved APIs at once?

Right-click a project, or Unassigned, and choose Move All to Project. Everything in it moves, locked APIs included.

I changed a saved request's address and pressed Send. What happens?

If you change a saved API's address or method and press Send, JSON Desk asks whether to save it as a new API or replace the saved one, so you don't overwrite a request by accident.

Does the API Client keep cookies?

Yes, cookies are kept between requests so sessions work. You can turn this off, and clear the cookies it holds, in Settings. An API with "Not for this API" turned on is sent without stored cookies.

Can I copy or protect a saved request?

Duplicate a request to try it against another environment. Lock a saved request so it can still be sent but not edited, renamed, moved or deleted.

Can I bring in requests from cURL, Postman or Swagger?

Yes. Import a cURL command, a Postman collection, or an OpenAPI or Swagger file in JSON or YAML, and copy any request as cURL. You can also export a project as a Postman collection.

Importing the same file again adds only what is new, so it is safe to re-import after the file changes.

If you don't use cURL, you can hide the cURL menu in Settings.

Are my tokens and API keys stored?

Header values, auth values and environment variables you save are stored in the app's preferences as plain text, and are included in backups and in Postman collections you export. They never leave your Mac unless you send a request or share an export. Avoid saving live production secrets. Two things are never saved: the JWT screen's secret, and a login token the API Client uses automatically. Both stay in memory until you quit. Request history leaves out secrets in headers and the Auth tab, but it does keep request bodies and responses, so clear it if they contain sensitive data.

A request fails or times out. What should I check?
  • Make sure the right environment is active, so variables like {{baseUrl}} resolve to the server you expect.
  • Try the same address in a browser or with cURL to rule out the server or your network.
  • Raise the request timeout in Settings if the server is slow to respond.
  • Check whether the response says it was redirected, and whether cookies from an earlier request are changing the result.
Why does JSON Desk need network access?

Only for the API Client. Requests go straight from your Mac to the address you enter. The app doesn't contact any other server, and has no analytics of its own.

Menu bar and Shortcuts

How do I use the menu bar icon?

Copy some JSON, click the JSON Desk icon in the menu bar, and choose Format, Minify or Validate. The icon briefly shows a check when it worked, or a warning if the clipboard doesn't hold valid JSON. Format and Minify put the result back on your clipboard.

I can't see the menu bar icon.

When the menu bar is full, macOS hides icons that don't fit, especially on Macs with a notch. Quit a few menu bar apps or shorten the clock, and check the menu bar settings in System Settings to make sure JSON Desk is allowed to show its icon.

How do I use JSON Desk in Shortcuts or Spotlight?

Open the Shortcuts app, create a shortcut, and search for JSON Desk to add its actions to format, validate or convert JSON. Combine them with actions like Get Clipboard and Copy to Clipboard. The same actions are available from Spotlight.

Reporting a bug

Including these details helps us fix things quickly:

  • Your JSON Desk version (JSON Desk › About JSON Desk) and macOS version.
  • The screen you were on and the steps that lead to the problem.
  • What you expected to happen, and what happened instead.
  • A small sample of JSON that shows the problem. Remove passwords, tokens and personal data first.
  • A screenshot or screen recording, if it helps.
