Email us

Bug reports, feature requests and questions all go to the same inbox. You'll usually hear back within two working days.

Email support

What to include in a bug report

  • Your JSON Desk version (JSON Desk menu → About JSON Desk) and macOS version.
  • The screen you were on and the steps that lead to the problem.
  • What you expected to happen, and what happened instead.
  • A small sample of JSON that shows the problem, if one is involved. Remove passwords, tokens and personal data first.
  • A screenshot or screen recording, if it helps.

Common questions

What do I need to run JSON Desk?

A Mac running macOS 14 Sonoma or later.

Where is my data stored?

Your library (documents, projects, requests, schemas, queries and Recently Deleted) is a single file called store.json, inside the app's sandbox container on your Mac. To find it, open Finder, choose Go → Go to Folder, enter ~/Library/Containers, open the JSON Desk folder, then go to Data/Library/Application Support/JsonStudio.

The folder is named JsonStudio so libraries from earlier versions keep loading. Preferences and recent tool inputs are kept in macOS user defaults.

How do I back up my library or move it to another Mac?

Go to Settings and choose Export. This writes your whole library to one JSON file. On the other Mac, open Settings and choose Import, then pick that file.

Import replaces the library on that Mac; it doesn't merge with it. Export a backup there first if it has documents you want to keep.

I deleted something by mistake. Can I get it back?

Open Recently Deleted in the Library section of the sidebar and restore it. Deleted items are kept for the period set in Settings, then removed for good. Once an item is removed from Recently Deleted, it can only come back from a backup.

The app started with an empty library. Is my data gone?

Probably not. If JSON Desk can't read the library file, it first saves a copy named store.unreadable-<date>.json in the same folder, then starts a fresh library. Nothing is overwritten.

Email us with that file attached, or a description of what it contains, and we'll help you recover it. If you have a backup, you can also import it from Settings.

Does locking a document encrypt it?

No. Locking makes a document read-only so it can't be edited by accident. The library is stored as plain JSON, protected by your Mac user account and FileVault. Avoid keeping live production secrets in saved requests or documents.

Why does the app need network access?

Only for the API Client. When you send a request, it goes straight from your Mac to the URL you entered. The app doesn't contact any other server, and there is no analytics or update check of its own.

Is my JWT secret saved?

No. The secret you enter to verify or sign a token is never written to disk, so you'll need to enter it again after you quit the app.

Will formatting change my keys or numbers?

No. JSON Desk keeps keys in their original order and leaves number literals exactly as written, so 1.50 stays 1.50. Keys are only reordered if you turn on the sort-keys option in the Formatter.

Are there keyboard shortcuts?

⌘ K opens the command palette, where you can jump to any screen or action. ⌘ F searches the current editor or output.

How do I remove JSON Desk and all its data?

Export a backup first if you want to keep anything. Then drag JSON Desk from Applications to the Trash, and delete its folder from ~/Library/Containers to remove the library and settings.
